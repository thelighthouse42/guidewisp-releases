# GuideWisp tester downloads

GuideWisp is a Windows x64 overlay for asking World of Warcraft questions and reading answers with sources.

1. Open the [latest release](https://github.com/thelighthouse42/guidewisp-releases/releases/latest) and download the GuideWisp Setup EXE.
2. Run it under your normal Windows account. This beta is unsigned. On first install, Windows SmartScreen may show **More info → Run anyway**.
3. Open GuideWisp from its shortcut. Settings and saved keys from the portable edition carry over for the same Windows account. Future updates download in the background. Choose **Restart to update** when ready, or quit normally to install.
